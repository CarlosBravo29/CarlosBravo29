## 🚀 Featured Projects
### [Rubik's Cube Solver 🎲🧩](https://github.com/CarlosBravo29/Rubiks-Cube-Solver.git) <img src="https://img.shields.io/badge/STATUS-WIP-blue?style=flat" height="15" alt="Project Status: WIP">
A robotic system designed to detect, interpret, solve, and physically manipulate a Rubik's Cube.
- **Vision Pipeline:** Detects stickers, identifies colors, and converts the cube faces into a digital state using OpenCV.
- **Solving Engine:** Generates an efficient sequence of moves using the Kociemba two-phase algorithm.
- **Hardware Integration:** Sends the solution to a microcontroller that controls the system's actuators.
### [Resistor Detection Project ⚡](https://github.com/CarlosBravo29/PureCV-Resistor-Detector.git)
A classical computer vision system that detects and validates electronic resistors in real time without using machine learning.
- **Segmentation:** Combines HSV color segmentation and geometric analysis to locate resistor candidates.
- **Verification:** Uses rotated ROI extraction and intensity-profile peak detection to confirm color bands while rejecting non-resistor components.
